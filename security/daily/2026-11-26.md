### 1. [1Password 員工 GitHub 帳號遭入侵，部分客戶資料外洩 (Update on a security incident involving 1Password’s backend systems)](https://www.ithome.com.tw/news/180820) — [原廠公告](https://1password.com/blog/update-on-nov-2026-security-incident)

### 2. [Palo Alto Networks 修補已遭利用的 Fragnesia 核心漏洞 (PAN-SA-2026-0015 Security Bulletin: OSS CVEs Fixed in PAN-OS)](https://www.ithome.com.tw/news/180808) — [原廠公告](https://security.paloaltonetworks.com/PAN-SA-2026-0015)
