## 深入閱讀

### 1. [長路徑代理基準升級：LongHorizon-Harness 讓實際任務執行更可追蹤 (LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks)](https://huggingface.co/papers/2608.01964)
* **核心重點：** 針對長鏈任務的執行、修正與持續推理建立更完整的評測基礎，讓 agent 不只會答題也能跑流程。
* **相關標籤：** `#Agents` `#Benchmark` `#LongHorizon`

### 2. [以強化學習逐步生成代理技能：Skill-α 登場 (Progressive Agent Skill Generation via Reinforcement Learning)](https://huggingface.co/papers/2608.01678)
* **核心重點：** 把 skill 生成拆成可評估的序列編輯步驟，再用 rollback reward 提升生成品質。
* **相關標籤：** `#Skills` `#ReinforcementLearning` `#Agents`

### 3. [SKT：用可驗證合成資料大規模訓練技能使用能力 (SKT: Skill-Use Training at Scale via Verified Synthetic Data Generation)](https://huggingface.co/papers/2608.02287)
* **核心重點：** 以驗證過的合成資料訓練模型辨識與套用技能，補上「有技能但不會用」的落差。
* **相關標籤：** `#Skills` `#SyntheticData` `#Training`

### 4. [SWE-Touch：使用者在共享程式碼庫中「碰到程式」時，如何衡量 coding agent (SWE-Touch: Benchmarking Coding Agents When Users Touch the Code)](https://huggingface.co/papers/2608.02499)
* **核心重點：** 把使用者會同步改碼的真實協作情境納入 benchmark，檢驗 agent 在共享 workspace 的韌性。
* **相關標籤：** `#CodingAgents` `#Benchmark` `#Collaboration`

### 5. [UEmbed：同時輸出稀疏與稠密多模態嵌入 (UEmbed: Unified Sparse and Dense Multimodal Embeddings)](https://huggingface.co/papers/2608.02583)
* **核心重點：** 用單一 decoder-only 模型同時產生 sparse 與 dense 向量，讓搜尋與 RAG 流程更整合。
* **相關標籤：** `#Embeddings` `#Multimodal` `#RAG`
