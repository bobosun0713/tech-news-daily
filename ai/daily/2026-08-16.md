## 深入閱讀

### 1. [多代理系統正在遇到什麼問題？Anthropic 的觀察整理 (Patterns and problems in emerging multi-agent systems)](https://www.anthropic.com/research/multiagent-systems)
* **核心重點：** 盤點多代理協作的常見失敗模式，幫助團隊提早設計協調與評估機制。
* **相關標籤：** `#Agents` `#MultiAgent` `#Research`

### 2. [衡量自主 AI 研究能力：研究代理該怎麼評估 (Measuring Autonomous AI Research)](https://www.primeintellect.ai/blog/measuring-autonomous-research)
* **核心重點：** 將「自主研究」拆成可觀測的任務與指標，避免只看最終結果而忽略過程品質。
* **相關標籤：** `#AIResearch` `#Evaluation` `#Autonomy`

### 3. [AGCX：為什麼 AI agent 不是助理 (AGCX: Why AI Agents aren't assistants)](https://www.agcx.org)
* **核心重點：** 從產品定位與互動模式切入，主張 agent 與傳統 assistant 的工作方式本質不同。
* **相關標籤：** `#Agents` `#ProductDesign` `#UX`

### 4. [Vero：AI agent 能否建出可形式驗證的軟體倉庫？ (Vero: Can AI Agents Build Formally Verified Software Repositories?)](https://arxiv.org/abs/2608.13522)
* **核心重點：** 把 agent 放進形式驗證流程，檢驗它是否能產出更可靠的軟體成果。
* **相關標籤：** `#FormalMethods` `#Agents` `#Verification`
