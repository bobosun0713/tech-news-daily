## 📑 焦點摘要
- 今天的 AI 主線從代理式程式測試、端側模型，到瀏覽器與 harness 評測基準全面展開。
- 焦點不只是模型更大，而是 agent 能不能在真實工作流中讀 repo、調工具、再被可靠地評估。
- Microsoft 與 Liquid AI 分別把測試代理與端側 agentic 模型往實用化推進。
- Cloudflare 與 HarnessOpt-Bench 則把執行環境與評測方法一起拉回工程現場。

### 1. [Microsoft 開源 code-testing-generator：多語測試代理在模糊需求下明顯勝過 stock Copilot (Microsoft Open Sources code-testing-generator: a Polyglot Unit-Test Agent That Hits 92.1% Task Completion Versus 78.9% for Stock Copilot)](https://www.marktechpost.com/2026/08/06/microsoft-open-sources-code-testing-generator/)

### 2. [Liquid AI 推出 LFM2.5-2.6B：128K context、tool calling、open weights 的端側 agentic 模型 (Liquid AI Releases LFM2.5-2.6B: An On-Device Agentic Model With 128K Context, Tool Calling, And Open Weights)](https://www.marktechpost.com/2026/08/06/liquid-ai-lfm2-5-2-6b-on-device-agentic-model/)
* **核心重點：** 2.69B 參數模型把長上下文、工具呼叫與開放權重帶到裝置端，瞄準可部署的輕量 agent 場景。
* **相關標籤：** `#OnDevice` `#Agents` `#OpenWeights`

### 3. [Cloudflare Kitesurf：跑在 Workers V8 isolates 裡的 agent-first 無狀態瀏覽器 (Cloudflare Introduces Kitesurf: An Agent-First Web Browser That Runs Entirely in V8 Isolates on Cloudflare Workers)](https://www.marktechpost.com/2026/08/06/cloudflare-introduces-kitesurf-an-agent-first-web-browser-that-runs-entirely-in-v8-isolates-on-cloudflare-workers/)

* **相關標籤：** `#BrowserAgents` `#Cloudflare` `#Infrastructure`

### 4. [HarnessOpt-Bench：把 LLM 的 harness optimization 能力正式拉成基準 (HarnessOpt-Bench: Evaluating LLMs at Harness Optimization)](https://huggingface.co/papers/2608.06301)
* **核心重點：** 新基準把 prompt、tools、memory 與 orchestration 一起納入評測，補上 agent 系統優化缺少共通量尺的空白。
* **相關標籤：** `#Evaluation` `#Harness` `#Agents`
