## 深入閱讀

### 1. [Zetta ζ：閉環具身 Harness，讓實體智慧可自我演化 (Zetta ζ: An Efficient Closed-Loop Embodied Harness for Self-Evolving Physical Intelligence)](https://huggingface.co/papers/2608.16590)
* **核心重點：** 以閉環具身 harness 讓 critics 與 recovery skills 在線演化，提升機器人任務的成功率與探索效率。
* **相關標籤：** `#EmbodiedAI` `#Robotics` `#Evaluation`

### 2. [Co-RL：多代理強化學習如何長出無監督推理 (Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL)](https://huggingface.co/papers/2608.17253)
* **核心重點：** 透過多代理協作與同儕回饋，讓模型在沒有標註答案下也能學出更好的推理能力。
* **相關標籤：** `#MultiAgent` `#RL` `#Reasoning`

### 3. [SemaPLC：以驗證門檻保護 PLC 程式生成 (SemaPLC: A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation)](https://huggingface.co/papers/2608.18565)
* **核心重點：** 把編譯與 runtime 驗證接到 agent harness 後面，讓 PLC 程式生成先過驗證再交付。
* **相關標籤：** `#Agents` `#Verification` `#Industrial`

### 4. [Looped Language Models：讓工具呼叫更能多步組合 (Looped Language Models Improve Compositional Tool Calling)](https://huggingface.co/papers/2608.18171)
* **核心重點：** 用遞迴式推理提升複合工具呼叫表現，同時在準確率與計算成本之間做動態取捨。
* **相關標籤：** `#ToolCalling` `#Reasoning` `#Efficiency`

### 5. [OmniScientist：全模態、全領域的 AI 科學家 (OmniScientist: An Omni-Modal Omni-Discipline AI Scientist)](https://huggingface.co/papers/2608.13558)
* **核心重點：** 把異質證據與自主 agent 組合成端到端科學流程，朝跨模態、跨學科研究助手前進。
* **相關標籤：** `#ScientistAI` `#Multimodal` `#Autonomy`
