## 深入閱讀

### 1. [AgentGarten：可進化 agent 的 code worlds (AgentGarten: Code Worlds for Evolving Agents)](https://huggingface.co/papers/2610.12374)
* **核心重點：** 以 simulator + game engine + shared neural renderer 建出可互動世界，讓 agent 透過實作與回放逐輪進化。
* **相關標籤：** `#Agents` `#WorldModels` `#Simulation` `#HuggingFacePapers`

### 2. [多代理第一人稱世界模型：細粒度互動同步生成 (Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction)](https://huggingface.co/papers/2610.12299)
* **核心重點：** 把多個 ego stream 放進共享 token sequence 與 shared environment memory，同時維持動作一致、環境一致與身份一致。
* **相關標籤：** `#WorldModel` `#EmbodiedAI` `#MultiAgent`

### 3. [DreamTrue：動作忠實的 robot world model (DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training)](https://huggingface.co/papers/2610.12468)
* **核心重點：** 透過 counterfactual post-training 與動作空間對齊，改善機器人影片預測的動作跟隨與物理合理性。
* **相關標籤：** `#Robotics` `#WorldModel` `#VideoPrediction`

### 4. [OneSearch-VL：統一圖像與影片深度研究代理 (OneSearch-VL: Unified Multimodal Deep Research Agent for Image and Video)](https://huggingface.co/papers/2610.12419)
* **核心重點：** 用 VGEG 把視覺 grounding、外部檢索與 fact composition 串成同一條研究流程，再用 RL/SFT 強化證據可追溯性。
* **相關標籤：** `#Multimodal` `#AgenticAI` `#DeepResearch`

### 5. [SparseEngine：稀疏優先推論引擎 (SparseEngine: Sparse-First Inference Engine)](https://huggingface.co/papers/2609.39068)
* **核心重點：** 以 shared lifecycle contract、Chain Cache 與 Prefix-Cache Pruning 管理長上下文，並在多個 sparse 方法上拿到明顯吞吐增益。
* **相關標籤：** `#Inference` `#KVCache` `#Performance`
