## 深入閱讀

### 1. [Prime Agent：把 sub-agent 變成持久 IPython kernel 裡的函式呼叫 (Prime Intellect Releases Prime Agent: An Open-Source RLM Harness Where Sub-Agents Are Function Calls Inside Persistent IPython Kernel)](https://www.marktechpost.com/2026/08/06/prime-intellect-releases-prime-agent/)
* **核心重點：** 用 Recursive Language Model 把多代理協作收斂成可重入函式呼叫，降低上下文切換與工具編排摩擦。
* **相關標籤：** `#Agents` `#RLM` `#OpenSource`

### 2. [SkillOpt 顯示最佳化後的 agent skill artifact 可跨模型大小與 Codex / Claude harness 轉移 (Microsoft’s SkillOpt Shows Optimized Agent Skill Artifacts Transfer Across Model Scales and Between Codex and Claude Code Harnesses)](https://www.marktechpost.com/2026/08/05/microsoft-skillopt-agent-skill-transfer-portability/)
* **核心重點：** 重點不只 52/52，而是導出的 best_skill.md 能跨模型尺度與不同 coding harness 持續生效。
* **相關標籤：** `#Agents` `#Skills` `#Evaluation`

### 3. [ABSeeker：用答案回溯 credit assignment 訓練長鏈搜尋代理 (ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment)](https://huggingface.co/papers/2608.05102)
* **核心重點：** 把最終答案回溯到多步搜尋軌跡上配分 credit，補強長鏈 search agent 難以穩定學習的問題。
* **相關標籤：** `#Agents` `#LongHorizon` `#Training`

### 4. [ToolArtist：讓多模態模型在圖像生成時學會調工具、查知識、分步驟 (ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation)](https://huggingface.co/papers/2608.04436)
* **核心重點：** 把工具使用納入統一多模態模型，讓 open-world 圖像生成能結合檢索、規劃與外部知識。
* **相關標籤：** `#Multimodal` `#ImageGeneration` `#Tools`

### 5. [Personalization Mirage：持久記憶個人化模型其實會捏造使用者輪廓 (The Personalization Mirage: How LLMs Fabricate User Profiles, and Why Self-Monitoring Misleads)](https://huggingface.co/papers/2608.04570)
* **核心重點：** 研究指出模型會過度推斷使用者屬性，而自我監測又容易誤判，直接衝擊記憶型代理的可信度。
* **相關標籤：** `#Personalization` `#Memory` `#Reliability`
