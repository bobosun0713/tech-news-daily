## 深入閱讀

### 1. [可視世界評估再進一步：HarnessEval-W 讓 agent 自動評測視覺世界 (HarnessEval-W: Agentifying the Evaluation of Visual Worlds)](https://huggingface.co/papers/2608.16859)
* **核心重點：** 把視覺世界的評估流程 agent 化，讓測試、採樣與比較更自動化。
* **相關標籤：** `#Agents` `#Evaluation` `#Multimodal`

### 2. [Agentic Transaction：把 ACID 約束搬進代理系統設計 (Agentic Transaction: Towards ACID-Compliant Agent Systems)](https://huggingface.co/papers/2608.13900)
* **核心重點：** 嘗試把交易一致性的思維引入 agent 流程，降低多步驟任務的狀態污染與失敗擴散。
* **相關標籤：** `#Agents` `#Transactions` `#Reliability`

### 3. [UI-Mate：用 in-context demonstrations 推進開源 GUI agent (UI-Mate: Advancing Open-Weight Foundation GUI Agents with In-Context Demonstrations)](https://huggingface.co/papers/2608.15930)
* **核心重點：** 透過示範資料強化 GUI agent 的操作能力，朝通用桌面與網頁操作更近一步。
* **相關標籤：** `#GUIAgents` `#Demonstrations` `#OpenWeight`

### 4. [VibeWorlding：多模態代理能否端到端建構 3D 開放世界？ (VibeWorlding: Can Multimodal Agents Construct 3D Open Worlds End-to-End?)](https://huggingface.co/papers/2608.15265)
* **核心重點：** 研究多模態 agent 是否能從零建構 3D 世界，檢驗端到端生成與控制能力。
* **相關標籤：** `#Multimodal` `#WorldModels` `#Agents`

### 5. [Meet SAM：零配置、零信任的 AI 代理 P2P 網路 (Meet SAM (Sovereign Agent Mesh): A Zero-Config, Zero-Trust P2P Network for AI Agents)](https://www.marktechpost.com/2026/08/18/meet-sam-sovereign-agent-mesh-a-zero-config-zero-trust-p2p-network-for-ai-agents/)
* **核心重點：** 介紹可讓多代理安全互連的 P2P 網路層，降低 agent 協作與發現成本。
* **相關標籤：** `#AgentMesh` `#Networking` `#Security`
