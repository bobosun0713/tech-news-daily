## 📑 焦點摘要
- 今天的 AI 焦點落在 4D 影片生成、群組影像身份對齊、與可演化的 agent harness。
- 幾篇研究都在回答同一個問題：模型不只要更強，還要更可驗證、更可持續更新。
- 這波更新顯示，agent 工具鏈、長上下文推理與持續改善仍是最核心的研究戰場。

## 深入閱讀

### 1. [4DAnyone：從單目影片生成可重建的 4D 人物 (4DAnyone: Create Anyone in 4D from a Casual Monocular Video)](https://4danyone.github.io/)
* **核心重點：** 透過多視角一致影片與 4D Gaussian Splatting，把單目影片升級成可操作的 4D 人體表示。
* **相關標籤：** `#3DVision` `#VideoGeneration` `#Reconstruction`

### 2. [WithEveryone：群組影像生成的身份與構圖統一規劃 (WithEveryone: Unified Planning and Identity Grounding for Group Image Generation)](https://doby-xu.github.io/WithEveryone/)
* **核心重點：** 把身份 grounding 與群組布局計畫綁在一起，提升多人影像生成的一致性。
* **相關標籤：** `#ImageGeneration` `#IdentityGrounding` `#Planning`

### 3. [Repo0：設計驅動的零到全代碼生成 (Repo0: Design-Driven Zero-to-All Code Generation)](https://huggingface.co/papers/2608.19854)
* **核心重點：** 以雙圖結構與模組化演化，嘗試從自然語言需求生成完整軟體倉庫。
* **相關標籤：** `#CodeGeneration` `#SoftwareEngineering` `#Agents`

### 4. [FlashPrefill V2：面向長上下文 LLM 服務的塊稀疏預填注意力 (FlashPrefill V2: Block-Sparse Prefill Attention for Long-Context LLM Serving)](https://github.com/qhfan/FlashPrefillv2)
* **核心重點：** 以稀疏注意力與 GPU 最佳化降低長上下文預填成本，讓推理更省時省錢。
* **相關標籤：** `#LLMServing` `#Attention` `#Performance`

### 5. [Hierarchical Self-Improvement：可針對任務持續演化的 agent harness (Hierarchical Self-Improvement: A Framework for Task-Specific Evolvable Agent Harnesses)](https://huggingface.co/papers/2608.08466)
* **核心重點：** 讓固定 backbone 的 agent 透過階層式自修改，持續生成更好的任務執行 harness。
* **相關標籤：** `#Agents` `#SelfImprovement` `#Harness`
