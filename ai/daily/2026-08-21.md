## 深入閱讀

### 1. [EnvHarness：讓靜態世界變成 agent 訓練場 (EnvHarness: Awakening Static Worlds for Agent Learning)](https://huggingface.co/papers/2608.19880)
* **核心重點：** 把靜態環境轉成可互動訓練場，讓 agent 學習更接近真實任務。
* **相關標籤：** `#Agents` `#Training` `#Evaluation`

### 2. [FACET：保留來源意圖與可執行狀態的終端任務合成 (FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis)](https://huggingface.co/papers/2608.18580)
* **核心重點：** 強調 terminal 任務合成時要保留來源意圖與可執行狀態，降低資料漂移。
* **相關標籤：** `#Terminal` `#Synthesis` `#Agents`

### 3. [SWE-bench Science：編碼 agent 能否解科學工程題？ (SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?)](https://huggingface.co/papers/2608.19799)
* **核心重點：** 以科學工程任務檢驗 coding agent 的實戰能力與泛化邊界。
* **相關標籤：** `#Benchmark` `#CodingAgents` `#Science`

### 4. [MemTrapBench：評測 LLM 記憶使用中的認知陷阱 (MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use)](https://huggingface.co/papers/2608.20202)
* **核心重點：** 聚焦模型記憶誤用與認知偏差，幫助找出長上下文脆弱點。
* **相關標籤：** `#Memory` `#Benchmark` `#LLM`

### 5. [SkillEvo：從多輪互動回饋長出自我更新技能 (SkillEvo: Self-Renewing Evolution Gradients from Multi-Turn Interaction Feedback)](https://huggingface.co/papers/2608.13120)
* **核心重點：** 利用多輪互動回饋讓技能持續演化，朝更自我更新的 agent 方向前進。
* **相關標籤：** `#Agents` `#Feedback` `#Evolution`
