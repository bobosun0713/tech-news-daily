## 📑 焦點摘要
- 今天的前端焦點偏向遷移與診斷：多語系搬家、跨端設計系統與請求取消都很實戰。
- React 與 Next.js 的交界仍是高風險區，尤其在 SSR、hydration 與 async 資料流上。
- 如果團隊同時做 Web 與 React Native，共用設計系統的建模方式會直接影響維護成本。
