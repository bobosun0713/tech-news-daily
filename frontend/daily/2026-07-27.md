## 深入閱讀

### 1. [現代化 React 動畫 UI 元件集 (Beautiful Animated UI Components for React)](https://componentry.dev)
* **核心重點：** 提供可直接組裝的動畫 UI 元件，縮短互動介面與動效開發時間。
* **相關標籤：** `#React` `#UI` `#Animation`

### 2. [正確性導向的前端框架：Effect × Elm 架構 (The front end framework for correctness: built on Effect, architected like Elm)](https://foldkit.dev/)
* **核心重點：** 以 Effect 與 Elm 式架構收斂狀態與副作用，提升大型前端的可預測性。
* **相關標籤：** `#FrontendArchitecture` `#Effect` `#Elm`

### 3. [Next.js 給 Agent 用：Eve.dev 的新定位 (Eve.dev: Next.js for Agents)](https://eve.dev/)
* **核心重點：** 把 Next.js 包裝成 agent app 的底座，顯示前端框架正朝 agent runtime 擴張。
* **相關標籤：** `#Nextjs` `#Agents` `#AppFramework`

### 4. [讓瀏覽器自己算：用 DOM 直接產生社群卡 (Let the Browser Do the Math Or: How I Learned to Stop Worrying and Love the DOM)](https://www.olafalders.com/2026/07/27/designing-social-cards-in-html/)
* **核心重點：** 用 HTML/CSS/DOM 直接完成社群卡產生，減少額外渲染或後製流程。
* **相關標籤：** `#DOM` `#CSS` `#Browser`

### 5. [React Native 的自架 OTA 更新服務 (Self-hosted over-the-air update service for React Native apps)](https://github.com/codemagic-ci-cd/codemagic-patch)
* **核心重點：** 讓 React Native 團隊可自架更新流程，提升交付彈性與版本控管能力。
* **相關標籤：** `#ReactNative` `#OTA` `#Delivery`
