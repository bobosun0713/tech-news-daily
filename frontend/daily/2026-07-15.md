## 深入閱讀

### 1. [GeoIcons：422 個可按需打包的地理圖示 (Introducing GeoIcons: 422 tree-shakable geographic icons)](https://dev.to/rushan123/introducing-geoicons-422-tree-shakable-geographic-icons-43i)
* **核心重點：** GeoIcons 以 named exports 覆蓋 255 個國家與 167 個區域，讓 React / Vue / Angular 專案只載入實際使用的圖示。
* **相關標籤：** `#React` `#Icon` `#Frontend`

### 2. [從 Liquid 到 Hydrogen：Shopify 無頭化前端實戰指南 (From Liquid to Hydrogen: A Developer's Honest Guide to Going Headless on Shopify)](https://dev.to/lucy1/from-liquid-to-hydrogen-a-developers-honest-guide-to-going-headless-on-shopify-2k98)
* **核心重點：** 文章整理 Liquid 與 Hydrogen 的定位差異，適合想把 Shopify 店面往更高控制度前端架構遷移的團隊。
* **相關標籤：** `#Shopify` `#React` `#Frontend`

### 3. [ProseMirror 富文字編輯器：協作、state tearing 與 API 複雜度 (ProseMirror Rich Text Editors: Addressing State Tearing, Collaboration Issues, and API Complexity for Reliable Development)](https://dev.to/pavkode/prosemirror-rich-text-editors-addressing-state-tearing-collaboration-issues-and-api-complexity-19ji)

* **相關標籤：** `#RichText` `#CollaborativeEditing` `#Frontend`

### 4. [為 React / Next.js 應用補強資安：npm audit 不夠 (Why `npm audit` Isn't Enough to Secure Your React or Next.js App)](https://dev.to/pruthvidarji1993/why-npm-audit-isnt-enough-to-secure-your-react-or-nextjs-app-3k58)

* **相關標籤：** `#Security` `#React` `#Nextjs`
