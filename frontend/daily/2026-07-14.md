## 深入閱讀

### 1. [Cloudflare 支持 Vite 的使命 (Cloudflare supports Vite's mission)](https://vite.dev/blog/cloudflare-supports-vite)
* **核心重點：** Cloudflare 進一步投資 Vite 生態，代表 Vite、Vitest、Rolldown 與 Oxc 的發展更接近基礎設施級別的長期支撐。
* **相關標籤：** `#Vite` `#Cloudflare` `#Tooling`

### 2. [Tailwind CSS v4.3：捲軸、新色彩與更多更新 (Tailwind CSS v4.3: Scrollbars, new colors, and more)](https://tailwindcss.com/blog/tailwindcss-v4-3)
* **核心重點：** 這版更新把捲軸、色彩與一些實務細節補齊，延續 Tailwind v4 對設計系統與開發體驗的持續打磨。
* **相關標籤：** `#TailwindCSS` `#DesignSystem` `#Frontend`

### 3. [tesseract.js：純 JavaScript OCR 引擎持續受關注 (Pure Javascript OCR for more than 100 Languages)](https://github.com/naptha/tesseract.js)
* **核心重點：** 這個純 JavaScript OCR 專案仍維持高熱度，對瀏覽器端文字辨識、無伺服器影像處理與前端自動化很有參考價值。
* **相關標籤：** `#JavaScript` `#OCR` `#OpenSource`

### 4. [Material UI：React 元件庫依舊是日常主力 (Material UI: Comprehensive React component library that implements Google's Material Design. Free forever.)](https://github.com/mui/material-ui)
* **核心重點：** MUI 仍是 React 生態最穩定的基礎元件庫之一，適合需要成熟設計系統與企業級一致性的團隊。
* **相關標籤：** `#React` `#DesignSystem` `#UI`

### 5. [frontend-slides：把前端技能變成可交付簡報 (Create beautiful slides on the web using a coding agent's frontend skills)](https://github.com/zarazhangrui/frontend-slides)
* **核心重點：** 這個專案把前端能力延伸到線上簡報與展示內容，凸顯 Web 技術也能直接承接內容輸出與作品集場景。
* **相關標籤：** `#Frontend` `#Slides` `#WebApp`
